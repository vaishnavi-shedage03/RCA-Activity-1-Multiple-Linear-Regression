# Activity 1: Multiple Linear Regression

## Subject
Regression and Classification Algorithms

## Objective
To implement Multiple Linear Regression using the Diabetes dataset and evaluate model performance.

## Dataset Details
- Dataset Name: Diabetes Dataset
- Total Records: 442
- Input Features: 10 numerical features
- Target Variable: Disease Progression

## Algorithms Used
1. Simple Linear Regression
2. Multiple Linear Regression

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Implementation
- Dataset loading and inspection
- Data cleaning and preprocessing
- Descriptive statistical analysis
- Scatter plots and correlation heatmap
- Manual least squares calculation
- Train-test split (80:20)
- Simple and Multiple Linear Regression
- Model evaluation using MAE, MSE, RMSE, R² and Adjusted R²
- Residual analysis
- Multicollinearity checking using VIF
- New data prediction
